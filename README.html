Expense Pilot 0.8.1

a clearer view of every dollar

Self-hosted expense tracking for sole traders and people tracking employment expenses.

What changed

  • Logout revokes the session on the server. Copied cookies cannot restore a logged-out session. Existing logins must sign in again after upgrading.
  • Password attempts are limited by account and source address. PDF parsing has separate memory and time limits, and image uploads have stricter limits.
  • Owner and tax-agent accounts only. Employee sign-in, invitations and reactivation are removed. Historical employee records are preserved.
  • Updated dependencies and an automated dependency vulnerability check.

Install or update

Use the current installation and update guide for Unraid settings, data paths, backup instructions and feature documentation. The image is ghcr.io/chrisk0007/expense-pilot:latest; version 0.8.1 is also published after checks pass.

Back up your appdata, then use the Unraid Docker page to update Expense Pilot. Retain the existing /data mapping and session.key. Financial records and receipt files are not encrypted by the application; protect your server and backups.

Secure access

Use HTTPS and COOKIE_SECURE=true. Enable authenticator 2FA in Settings. Local HTTP is unencrypted and remains available for trusted LAN setup, with a warning on sign-in. Do not expose port 8788 directly to the internet; use a VPN or HTTPS reverse proxy.

Tax agents can see all financial records, including personal expenses and unfiled receipts. They are read-only by default. The owner can grant financial read/write access, but account administration and outgoing email remain owner-only.

iPhone app

The existing iPhone development app works with this server update. See the free Xcode installation guide. No Xcode reinstall is needed for these server fixes.
