# Manual domestic and overseas overnight costs

Open **Overnight spending**, create or select a trip, then choose **Log actual cost (no receipt)**. The same action is available from **Spending & allowances**. Enter the payment's date, merchant, cost type and actual AUD amount. Notes, evidence basis and original foreign-currency details are optional. Foreign amounts and the conversion source are retained in the expense notes; totals use the entered AUD amount, with no automatic exchange-rate lookup.

Costs use the existing expense ledger and start as **To review**. Reopen the existing record to edit it or attach evidence later. Check existing receipts and bank-linked expenses before adding a payment again. The form shows recorded trip costs and warns about matching date/merchant/amount records. Retrying an unchanged save in the same form uses the existing durable request reference. A changed uncertain request is stopped so the trip can be checked first.

Saving without an attachment is a logging feature, not a declaration that a receipt is unnecessary for tax. Actual costs, allowances and ATO reasonable amounts remain separate. A saved manual cost does not automatically confirm a deduction. Existing trip claim-review controls remain unchanged.

For employees, travel-allowance record-keeping exceptions depend on the applicable allowance, eligible expenses actually incurred and reasonable amounts. Overseas accommodation requires written evidence. Business/ABN travel follows different rules; the employee allowance exception must not be assumed. See the [ATO travel-allowance record-keeping guidance](https://www.ato.gov.au/individuals-and-families/income-deductions-offsets-and-records/deductions-you-can-claim/work-related-deductions/cars-transport-and-travel/overnight-travel-expenses-and-allowances/travel-allowances-for-overnight-travel/record-keeping-exceptions-for-travel-allowance-expenses) (checked 28 November 2026). This change does not modify tax rates or determine a user's eligibility.

No schema migration, historical-record rewrite, currency-rate service, iOS release or deployment is included. Beta.14 is an unreleased PR candidate; the published beta remains beta.13.
