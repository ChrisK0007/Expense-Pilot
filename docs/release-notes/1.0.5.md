Expense Pilot's Docker release is prepared for public distribution and Unraid Community Apps. The iPhone companion remains in testing.

- Package the application from the cleaned repository, including synthetic test examples and version-matched source checksums.
- Retain the exact Debian source packages, patches and build instructions; Python source distributions; CPython source; and detected Pillow FriBiDi source in the image. Download them through **Source code & licences** or this release's assets.
- Fail the image build when required dependency sources cannot be collected or verified. Refresh Debian runtime packages during the build.
- Add Community Apps repository metadata, a public icon, template identity, support/licence links and installation guidance. AI remains configured in the app and the setup token remains optional.
- Publish source archives, notices, inventories and checksums alongside the stable GitHub release.

Install: `ghcr.io/chrisk0007/expense-pilot:1.0.5` or the moving stable tag `latest`.

The image is Linux AMD64. It is larger because dependency source archives accompany the binaries. Optional AI runs in your own service or chosen API provider. No central Expense Pilot account or relay is required.

Existing installations: back up the complete `/data` directory, update the image and preserve the same data mapping and deployment settings. No new database migration is introduced. Existing receipts, settings and sessions are retained. Rollback uses the old image and its matching backup.

Community Apps listing requires separate Unraid review; a GitHub release does not mean the listing has been approved. See [installation](https://github.com/ChrisK0007/Expense-Pilot/blob/main/docs/public-release.md) and the [Community Apps submission guide](https://github.com/ChrisK0007/Expense-Pilot/blob/main/docs/releases.md#unraid-community-apps).
